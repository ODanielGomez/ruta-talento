# Ruta Talento

Aplicación web para rutas personalizadas de capacitación y clima laboral.

## Archivos

- `index.html`: vista para la persona trabajadora.
- `admin.html`: panel de Gestión Humana.

La versión actual es un prototipo visual. La siguiente etapa conectará autenticación, catálogos, resultados y enlaces individuales con Firebase.

## Publicación

Este repositorio está preparado para publicarse con GitHub Pages desde la rama `main` y la carpeta raíz.
